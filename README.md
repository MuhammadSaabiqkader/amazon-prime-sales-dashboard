Amazon Prime Sales Analysis Dashboard

An interactive web dashboard built to demonstrate data visualization and content analysis.

Live Demo

"Open the Dashboard" (https://muhammadsaabiqkader.github.io/amazon-prime-sales-dashboard/)

Features

- Interactive rating filter
- Release-period filter
- Quality filter
- KPI cards and visual charts
- Reset filters
- Responsive dark-themed interface

Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js

Project Overview

This project demonstrates how interactive filters and visualizations can be used to explore catalogue insights and trends.

Data Disclaimer

This is a portfolio demo using illustrative sample data. It is not connected to a live Amazon database or a real Power BI dataset. Displayed figures are examples, not verified Amazon sales results.

Run Locally

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Use the filters to explore the demo.

An internet connection is required for externally hosted chart libraries.
